Quick Start

3 steps. 1 minute. Zero boilerplate.

1

Define Your State

State is just a C# record with transformation methods:

CounterState.cs
public record CounterState(int Count, string? LastAction = null)
{
    // State methods are pure functions that return new state
    public CounterState Increment() =>
        this with { Count = Count + 1, LastAction = "Incremented" };

    public CounterState Decrement() =>
        this with { Count = Count - 1, LastAction = "Decremented" };

    public CounterState Reset() =>
        this with { Count = 0, LastAction = "Reset" };
}
2

Register the Store

In your Program.cs:

Program.cs
// One-liner registration with all features
builder.Services.AddStoreWithUtilities(
    new CounterState(0),
    (store, sp) => store.WithDefaults(sp, "Counter"));
3

Use in Components

Inherit from StoreComponent and you're done:

Counter.razor
@page "/counter"
@inherits StoreComponent<CounterState>

<div class="counter">
    <h1>@State.Count</h1>
    <p>@State.LastAction</p>

    <button @onclick="@(() => UpdateAsync(s => s.Increment()))">➕ Increment</button>
    <button @onclick="@(() => UpdateAsync(s => s.Decrement()))">➖ Decrement</button>
    <button @onclick="@(() => UpdateAsync(s => s.Reset()))">🔄 Reset</button>
</div>
That's it!

No actions, no reducers, no dispatch. Just call UpdateAsync() with your state method.
